# Typing Paws 2.0 — ROADMAP

依照 `docs/proposal.md` 第十節的優先順序排列，區塊內照相依關係由上往下做。
每次只做一個項目；每項的「完成條件」就是手動驗證的依據。完成後把 `- [ ]` 改成 `- [x]`。

**待決定**（做到該區塊前要先定案）
- LLM 用哪一家、哪個模型（弱點特訓開工前）
- text-to-image 用哪個模型或服務（AI 生成怪物開工前）

**刻意與 1.0 版不同的地方**（1.19 驗收時對照）
- 小按鈕（例如「清除紀錄」）滑過、按下時陰影會跟著變化（3px → 滑過 4px、按下位移 2px 且陰影 1px）；1.0 版的陰影固定 3px。
- 清除紀錄改用遊戲內的確認視窗（Enter 是「先不要」）；1.0 版用瀏覽器內建的 `confirm`。
- WPM 走勢圖改用 Chart.js 畫在 canvas 上，外觀照 1.0 版做（基準線、粉紅色面積、綠／粉紅點、最近一場的數字），但不會像素相同，滑鼠提示也改成 Chart.js 的樣式；1.0 版是手刻 SVG。
